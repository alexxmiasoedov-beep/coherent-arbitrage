# Раунд 1: наивная стратегия (статичная β + коинтеграция) — вывода нет, эджа нет

**Дата:** 2026-07-12
**Ветка/коммиты:** `main` (abe3114 … ceb61b9), скан 1m — `research/kalman-dynamic-hedge` (1ba6a87, 9b65d76)

## Постановка

Классический pairs trading: тест Энгла-Грейнджера на коинтеграцию, статичная β,
вход по |z| > 2, выход при z ≈ 0, стоп |z| ≥ 3.5. Paper-торговля на BingX perpetual futures.

## Результаты

1. **Убыточна на ликвидной крипте.** 30-дневный out-of-sample бэктест:
   PnL **−58 USDT**, Sharpe **−4.38**.

2. **Первоначальный «плюс» был миражом** — он держался только на токенизированной
   экзотике BingX (нефть/золото/акции), которую вживую не оторговать.
   Юниверс отфильтрован от синтетики (`NCCO*/NCS*/*2USD`, см. `src/data.py::is_synthetic`).

3. **Перебор параметров** (`run_sweep.py`) нашёл прибыльную конфигурацию
   (entry 3.0 + фильтры), но **walk-forward на 4 периодах** (`walk_forward.py`)
   показал прибыль лишь на **1 окне из 4** — классическая подгонка под историю.

4. **Скан 1m по 60 монетам** (`scan_cointegration.py`): 271 пара «коинтегрирована»
   на всём окне (in-sample), но walk-forward-валидация на 7 фолдах
   (`validate_pairs.py`) оставила **0 робастных пар**; суммарный OOS PnL
   **−1182 USDT**. Низкий p-value коинтеграции ≠ прибыльность вне выборки.

## Вывод

Наивная стратегия со статичной β **не имеет тредебельного эджа** на ликвидных
крипта-перпах. Кажущаяся прибыльность — артефакт in-sample-подгонки и
неторгуемой синтетики. Следующая гипотеза — динамическая β (фильтр Калмана),
см. отчёт раунда 2.

## Инструменты воспроизведения

```bash
python run_backtest.py       # out-of-sample бэктест
python run_sweep.py          # перебор параметров
python walk_forward.py       # walk-forward-валидация (тест на переобучение)
python compare_timeframes.py # сравнение таймфреймов сигнала
python scan_cointegration.py 1m 14400 150   # скан юниверса (с кэшем в .cache/)
python validate_pairs.py     # отсев переобученных пар
```
