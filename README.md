# Когерентный арбитраж (coherent-arbitrage)

Бот статистического арбитража на **BingX (perpetual futures)**: сам находит
коинтегрированные пары монет и торгует на возврате их спреда к среднему
(pairs trading / mean-reversion).

## Идея

Две монеты, которые не просто коррелируют, а **коинтегрируют**, движутся связанно:
их спред `spread = P_y − β·P_x` колеблется вокруг среднего. Когда спред уходит
далеко (z-score > 2), ставим на возврат: шортим «дорогую» ногу, лонгуем «дешёвую».
Закрываемся при возврате к среднему (z ≈ 0) или по стопу, если связь порвалась.

## Как работает бот

```
цикл каждые POLL_INTERVAL_SEC:
  ├─ (раз в REDETECT_EVERY_MIN) детекция коинтегрированных пар → watchlist
  ├─ тянем текущие цены нужных контрактов с BingX
  ├─ закрываем позиции: take-profit |z|≤0.5  или  стоп |z|≥3.5
  └─ открываем новые: |z|>2, в пределах лимита MAX_OPEN_POSITIONS
```

**Направление:** `z>+2` → SHORT spread (sell y, buy x); `z<−2` → LONG spread.

## Запуск

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

python run_screener.py     # посмотреть текущие коинтегрированные пары
python run_bot.py --once   # один шаг бота (paper по умолчанию)
python run_bot.py          # бесконечный цикл
```

## Режимы

- **`MODE="paper"`** (по умолчанию) — сделки **симулируются** по текущей цене с учётом
  комиссии. Реальные деньги не задействованы. Так проверяют стратегию перед боем.
- **`MODE="live"`** — реальные ордера на BingX. Нужны ключи в окружении:
  ```bash
  export BINGX_API_KEY=...
  export BINGX_API_SECRET=...
  ```

## ⚠️ Риски

- Главный риск — **разрыв коинтеграции**: спред не возвращается, а уходит (эмбарго,
  делистинг, смена режима рынка). Для этого есть стоп `|z|≥3.5`, но убыток возможен.
- Результаты на истории **не гарантируют** прибыль в реальной торговле (комиссии,
  проскальзывание, funding perpetual-контрактов).
- Начинать только с **paper**, затем малый капитал. Это не финансовый совет.

## Результаты исследования (важно)

Мы честно проверили стратегию на истории — **две разные методологии, оба вывода
отрицательные и согласованные**.

### Этап 1. Наивная стратегия (статичная β + коинтеграция)

1. **Убыточна на ликвидной крипте.** 30-дневный out-of-sample: PnL −58 USDT,
   Sharpe −4.38.
2. **Первоначальный «плюс» был миражом** — держался только на токенизированной
   экзотике BingX (нефть/золото/акции), которую вживую не оторговать. Поэтому юниверс
   отфильтрован от синтетики (`NCCO*/NCS*/*2USD`, см. `src/data.py::is_synthetic`).
3. **Перебор параметров** нашёл прибыльную конфигурацию (entry3.0 + фильтры), но
   **walk-forward на 4 периодах** показал: прибыль лишь на 1 окне из 4 (подгонка).
4. **Скан 1m по 60 монетам:** 271 пара «коинтегрирована» на всём окне (in-sample), но
   walk-forward-валидация (7 фолдов) оставила **0 робастных** — суммарный OOS PnL
   −1182 USDT. Низкий p-value ≠ прибыльность вне выборки.

### Этап 2. Динамический хедж (фильтр Калмана)

Гипотеза: статичная β «плывёт» → заменяем на онлайн-оценку β фильтром Калмана в
log-ценах (`src/kalman.py`), сигнал = стандартизованная инновация. Весь ряд после
burn-in — честный OOS (фильтр каузален). Разложили PnL на gross (до комиссий) и net:

| | 1m gross | 1m net | 1h gross | 1h net |
|---|---|---|---|---|
| entry_z=1.5 | **+48 386** | −169 949 | −664 | −19 780 |
| entry_z=2.0 | **+29 257** | −86 756 | −7 001 | −18 018 |
| entry_z=2.5 | **+17 662** | −44 392 | −6 567 | −13 096 |

- **На 1m gross положительный, но net глубоко в минусе:** эдж на сделку ~$0.04–0.05,
  а круг комиссий (тейкер 0.05%) ~$0.18 — комиссии в ~4× больше эджа.
- **Природа 1m-эджа — микроструктурный отскок bid-ask** на ценах закрытия: тейкер его
  не ловит (сам платит через спред). Подтверждение: **на 1h gross уже ≈0/отрицательный** —
  сигнал горизонтозависимый и к часу растворяется. Больший ТФ не лечит, а убивает сигнал.

**Общий вывод:** тредебельного эджа у mean-reversion стат-арба на крипта-перпах нет
ни на 1m (сигнал есть, но это неуловимый тейкером микроструктурный шум), ни на 1h
(сигнала нет). Монетизировать 1m-отскок можно лишь как маркет-мейкер с ребейтами и
низкой латентностью — это другая игра, не paper-бот на тейкер-ордерах.

Ценность проекта — не «денежный станок», а **корректный research-фреймворк**, который
это доказал двумя независимыми методами и уберёг от торговли вживую.

## Статус

🔬 Рабочий research-фреймворк (детекция, бэктест, sweep, walk-forward, динамический хедж,
paper-торговля). **Двумя независимыми методологиями** (наивная коинтеграция и Калман)
показано: тредебельного эджа у mean-reversion стат-арба на ликвидных крипта-перпах нет —
1m-сигнал есть, но это микроструктурный отскок, неуловимый тейкером; на 1h сигнал
исчезает. Возможные направления, если продолжать: маркет-мейкинг с ребейтами (другая
инфраструктура), funding-rate арбитраж, другой рынок. Это уже отдельные гипотезы.
