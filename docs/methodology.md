# Методология исследования

Заметки о том, как в этом проекте проверяются торговые гипотезы.
Итоговые цифры каждого раунда — в `reports/`.

## Принципы

1. **In-sample ничего не доказывает.** Любой результат обязан пройти
   out-of-sample / walk-forward-валидацию, прежде чем считаться сигналом.
2. **Net, а не gross.** PnL всегда раскладываем на gross / комиссии / net.
   Эдж меньше круга комиссий — не эдж.
3. **Торгуемый юниверс.** Синтетика BingX (токенизированные нефть/золото/акции,
   `NCCO*/NCS*/*2USD`) исключается — по ней нет реальной ликвидности.
4. **Каузальность.** Никакого заглядывания в будущее: фильтр Калмана каузален,
   walk-forward режет данные по времени.

## Раунд 1 — наивная коинтеграция (закрыт, эджа нет)

- Тест Энгла-Грейнджера → статичная β → z-score спреда.
- Вход |z|>2, выход z≈0, стоп |z|≥3.5.
- Проверка: OOS-бэктест, параметрический sweep, walk-forward (4 периода),
  скан 1m на 60 монетах + walk-forward на 7 фолдах.

## Раунд 2 — динамический хедж, фильтр Калмана (закрыт, эджа нет)

- Онлайн-оценка β фильтром Калмана в log-ценах (`src/kalman.py`).
- Сигнал — стандартизованная инновация фильтра; весь ряд после burn-in — честный OOS.
- Проверка: gross/net-разложение на 1m и 1h, свип entry_z/delta.
- Итог: 1m-эдж — микроструктурный отскок bid-ask, тейкером не монетизируется.

## Технические заметки

- Цены кэшируются в `.cache/` (переопределяется `ARB_CACHE_DIR`); кэши в git не идут.
- Скан, валидация и Калман параллелятся по ядрам CPU.
- Формат отчёта: `reports/ГГГГ-ММ-ДД-название.md` — дата, постановка, цифры,
  вывод, команды для воспроизведения.
