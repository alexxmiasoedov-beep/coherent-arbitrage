# Romanov Decor Studio — сайт по микроцементу

Полная копия сайта [romanovdecor.by](https://romanovdecor.by/) — микроцемент и наливные полы в Минске.

## Структура

- `index.html` — главная страница
- Остальные страницы лежат в корне без расширения `.html` (как на сервере): `microcement`, `floors`, `walls`, `bathroom`, `price`, `portfolio`, `calculator`, `blog`, `about` и т.д.
- `img/` — изображения
- `favicon.svg` — иконка сайта

Все стили и скрипты встроены прямо в HTML-страницы, шрифты подгружаются с Google Fonts.

## Как посмотреть локально

Открыть `index.html` в браузере. Внутренние ссылки рассчитаны на сервер (пути без расширений), поэтому для полноценной навигации лучше запустить локальный сервер, отдающий файлы как HTML.
